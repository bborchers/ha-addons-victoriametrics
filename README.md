Build repository for the VictoriaMetrics Home Assistant add-on.

The add-on runs the open-source VictoriaMetrics single-node server and stores
time-series data below its persistent Home Assistant add-on data directory.

To install it in Home Assistant, use the central [ha-addons repository](https://github.com/bborchers/ha-addons).

See [victoriametrics/DOCS.md](victoriametrics/DOCS.md) for configuration and usage details.
